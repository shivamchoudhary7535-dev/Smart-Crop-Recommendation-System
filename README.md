# 🌾 Smart Crop Recommendation System

A web-based Smart Crop Recommendation System designed to help farmers make better crop-related decisions using soil and environmental parameters.

The system provides crop recommendations, weather information, fertilizer guidance, crop-stage advisory, soil health analysis, estimated profit, AI-based disease detection and voice assistance.

---

## 🚀 Features

- 🌱 Smart Crop Recommendation
- 🌦️ Live Weather Information
- 🌧️ Weather Impact Analysis
- 🧪 Soil Health Score
- 💰 Estimated Crop Profit
- 🤖 AI Recommendation Confidence
- 💊 Fertilizer Schedule
- 🌾 Crop Stage Advisory
- 🦠 AI Disease Detection
- 🎙️ AI Voice Assistant
- 🚨 Weather Alerts
- 📊 Disease Risk Analysis
- 🗄️ MySQL Database Management
- 📑 Farmer Record Management
- 📥 Excel/Data Export
- 🌐 Hindi and English Language Support
